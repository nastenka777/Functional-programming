# Лабораторная работа №1. Функциональное программирование в JavaScript

Набор чистых функций для работы с массивами, функция высшего порядка
и построенные на их основе математические операции.

## Структура

```
lab1/
├── index.js              — демонстрация на предустановленных данных
├── cli.js                — интерактивный режим: ввод своих данных
├── package.json
└── src/
    ├── arrayUtils.js     — чистые функции для работы с массивами
    ├── higherOrder.js    — функция высшего порядка applyToEach
    ├── operations.js     — математические операции
    └── parse.js          — чистые функции разбора введённых строк
```

## Запуск

Демонстрация на предустановленных данных (можно указать номер раздела:
`node index.js 3`):

```bash
node index.js
```

Интерактивный режим — числа и объекты вводит пользователь:

```bash
node cli.js
```

## Функции

| Функция | Назначение |
| --- | --- |
| `filterEven(numbers)` | новый массив только из чётных чисел |
| `squareAll(numbers)` | новый массив квадратов чисел |
| `filterByProperty(items, property)` | объекты, у которых есть заданное свойство |
| `sum(numbers)` | сумма элементов массива |
| `applyToEach(fn, items)` | применяет `fn` к каждому элементу, возвращает новый массив |
| `sumOfEvenSquares(numbers)` | сумма квадратов всех чётных чисел |
| `averageAboveThreshold(items, property, threshold)` | среднее значений свойства, превышающих порог |
| `parseNumbers(input)` | разбор строки в массив чисел |
| `parseObjects(input)` | разбор строки в массив объектов |
