# Лабораторная работа №2. Веб-приложение «Список задач»

Приложение позволяет добавлять задачи, отмечать их выполненными,
удалять и фильтровать по статусу. Логика построена на чистых функциях
и иммутабельных данных.

## Структура

```
lab2/
├── index.html            — разметка интерфейса
├── styles.css            — оформление
├── checks.js             — проверка чистоты функций (Node.js)
└── src/
    ├── taskModel.js      — чистые функции работы со списком задач
    ├── store.js          — чистый reducer и хранилище состояния
    ├── view.js           — чистые функции разметки и отрисовка
    └── app.js            — связывание модели, хранилища и DOM
```

## Запуск

Открыть файл `index.html` в браузере (двойным щелчком).

Проверка чистоты функций модели:

```bash
node checks.js
```

## Функции модели

| Функция | Назначение |
| --- | --- |
| `addTask(tasks, title)` | новый список с добавленной задачей |
| `toggleTask(tasks, id)` | новый список с инвертированным статусом задачи |
| `removeTask(tasks, id)` | новый список без указанной задачи |
| `filterTasks(tasks, filter)` | отбор по статусу: `all`, `active`, `done` |
| `countTasks(tasks)` | статистика: всего, выполнено, осталось |
| `nextId(tasks)` | следующий свободный идентификатор |
